# Omar Osama — Personal Link Hub (3D Ultra UI Edition)

Ultra-premium personal link hub with interactive 3D Canvas background and Glassmorphic cards.

## Deployment to GitHub Pages
1. Push `index.html`, `style.css`, `script.js`, `robots.txt`, and `sitemap.xml` to your GitHub repository (`omar-osama-ali.github.io`).
2. Navigate to **Settings** > **Pages** on GitHub.
3. Select `main` branch and `/ (root)` folder, then click **Save**.
