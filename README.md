# Omar Osama — Colorful Link Hub

A static, responsive personal link hub built with HTML, CSS, and vanilla JavaScript.

## Visual direction
Warm off-white canvas, ink/navy typography, cobalt blue, coral, green, yellow, violet, and cyan accents. The hero illustration is built from CSS shapes (not an AI-generated image). No cursor-following beam, scroll-triggered animations, emoji icons, pill-shaped buttons, fake metrics, or fake reviews.

## Files
- `index.html` — main link hub
- `style.css` — responsive styling and CSS-built 3D illustration
- `script.js` — copyright year and optional consent-gated analytics
- `privacy.html`, `terms.html`, `cookies.html`, `refunds.html` — informational policy pages
- `404.html` — custom GitHub Pages not-found page
- `favicon.svg` — simple vector favicon
- `robots.txt`, `sitemap.xml` — crawl configuration

## Deployment
Upload the files to the root of the repository/folder served at `https://omar-osama-ali.github.io/Link-Hub/`. No build step or backend is required.

## Analytics and cookies
Google Analytics is disabled by default. Leave `GA_MEASUREMENT_ID` blank in `script.js` to keep analytics and the consent notice disabled. If analytics is enabled, add the Measurement ID and test consent behavior and local requirements before publishing.

## Before publishing
- Verify the WhatsApp and telephone destinations are current.
- Add any required Google Search Console verification token if needed.
- Review policy pages for your actual situation and applicable law. These simple informational pages are not legal advice.
- Confirm all links work after deploying.
